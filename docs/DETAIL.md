# 进度树（Progress Tree）

在 DeepSeek Harness 的右侧栏实时展示 AI 的任务树：当前节点、每一步状态、阻塞原因和产物。

## 它解决什么

AI 执行长任务时，用户只能看到滚动的工具调用，无法快速判断：

- 现在做到哪一步了？
- 接下来要做什么？
- 卡在哪里了？
- 已经产出了哪些文件？

进度树把这些问题压缩成一个可扫读的右侧栏面板。

运行中，面板会直接显示 AI 的流式叙述和正在运行的工具（客户端订阅会话事件流，不写投影）；
当用户改了需求而计划还没更新时，顶部会出现「新任务规划中…」和最新请求，旧计划折叠为「上一任务」；
输入框上方的紧凑进度条会同步显示运行脉冲点。

节点可以手动勾选完成，也可以跳过：跳过项保留记录、显示为划线淡灰，并从进度分母中排除。
当后续步骤开始时，同一父节点下更早的待开始步骤会自动确认，避免树长期停在旧进度上。

## 怎么用

安装并启用后，AI 在多步任务开始时会调用 `progress_plan` 建立任务树，之后用
`progress_update` 推进节点状态、用 `progress_note` 写过程记录；需求变化时用
`progress_plan` 重建，或用 `progress_update remove:true` 删除过期节点。

在右侧栏的“添加页签”里选择“进度树”，或从右侧栏引导卡片打开。

节点状态颜色：

- 待开始（灰）
- 进行中（蓝，脉冲）
- 已完成（绿）
- 阻塞（红）
- 暂停（黄）
- 已跳过（划线淡灰）

## 工具

| 工具 | 作用 |
| --- | --- |
| `progress_plan` | 建立/替换任务树：标题、摘要、并行泳道、节点 |
| `progress_update` | 更新节点状态、备注、产物、父节点或泳道；也可新增节点 |
| `progress_note` | 追加一条过程记录 |

## 数据与隐私

任务树状态由本插件在会话内折叠 `tool/call` 与 `tool/result` 得到，不新增会话事件类型，
不写额外文件，不调用 `appendPluginRecord`。原始会话日志仍是唯一真相。

## 自动活动追踪

右侧栏不只显示模型主动维护的任务树：宿主会自动记录每条用户请求、正在运行的工具及其明细、
开始时间与模型最近的可见叙述。模型即使完全不调用进度工具，用户也能在「当前任务」卡与单节点
当前任务树里看到“现在在做什么”和已用时；工具名会转成“读取文件 / 运行命令 / 搜索代码”等人话。
上一份计划会折叠为「上一任务」并淡化，避免新旧进度混在一起。
