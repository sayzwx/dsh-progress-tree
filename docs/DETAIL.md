# 进度树（Progress Tree）

在 DeepSeek Harness 的右侧栏实时展示 AI 的任务树：当前节点、每一步状态、阻塞原因和产物。

## 它解决什么

AI 执行长任务时，用户只能看到滚动的工具调用，无法快速判断：

- 现在做到哪一步了？
- 接下来要做什么？
- 卡在哪里了？
- 已经产出了哪些文件？

进度树把这些问题压缩成一个可扫读的右侧栏面板。

## 怎么用

安装并启用后，AI 在多步任务开始时会调用 `progress_plan` 建立任务树，之后用
`progress_update` 推进节点状态、用 `progress_note` 写过程记录。

在右侧栏的“添加页签”里选择“进度树”，或从右侧栏引导卡片打开。

节点状态颜色：

- 待开始（灰）
- 进行中（蓝，脉冲）
- 已完成（绿）
- 阻塞（红）
- 暂停（黄）

## 工具

| 工具 | 作用 |
| --- | --- |
| `progress_plan` | 建立/替换任务树：标题、摘要、并行泳道、节点 |
| `progress_update` | 更新节点状态、备注、产物、父节点或泳道；也可新增节点 |
| `progress_note` | 追加一条过程记录 |

## 数据与隐私

任务树状态由本插件在会话内折叠 `tool/call` 与 `tool/result` 得到，不新增会话事件类型，
不写额外文件，不调用 `appendPluginRecord`。原始会话日志仍是唯一真相。
